# Security review — M1 Rooms and realtime

Date: 13 November 2026. Scope: team key sessions, room creation and joining,
the room Durable Object and its WebSocket protocol, the Angular room screens,
Turnstile, rate limits, CSP changes.

## What changed

- `POST /api/session`: the shared team key becomes a signed, 90-day team
  session. The app stores the session, never the key.
- `POST /api/rooms` (team session, Turnstile, rate limit) and
  `POST /api/rooms/:code/join` (team session, rate limit).
- `GET /api/rooms/:code/ws`: WebSocket, same-origin only, team session as a
  subprotocol, then the participant token as the first message.
- One Durable Object per room: participants, host role, kick, hand-over,
  leave, end, automatic hand-over after 60 s, 30-minute cap, close after 5
  minutes empty. Closed rooms delete all their storage.
- App: team key form, create and join, share link and QR code, live
  participant list, host controls, reconnecting connection, toasts.
- CSP: `https://challenges.cloudflare.com` for Turnstile's script and frame;
  `wss://` to the own host; a Trusted Types policy that only accepts the
  Turnstile script URL. Subresource Integrity on all built scripts and styles.

## Findings

| #   | Finding                                                                                                                                | Severity | Status                                                                                   |
| --- | -------------------------------------------------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------- |
| F1  | The WebSocket route did not require the team session: anyone could probe which room codes exist (404 vs upgrade) and hold sockets open | Medium   | Fixed: team session offered as a subprotocol and verified before any room lookup         |
| F2  | No cap on sockets per room: one device could open hundreds                                                                             | Low      | Fixed: 60 sockets per room, then 503                                                     |
| F3  | Rate limits are approximate, per Cloudflare location, and fail open if the limiter is down                                             | Low      | Accepted: team key, Turnstile and the 20-person cap still apply                          |
| F4  | The team key is shared, so its strength decides how hard brute force is                                                                | Medium   | Mitigated: 10 tries/min/IP, minimum 8 characters enforced, setup asks for 4 random words |
| F5  | A kicked participant can rejoin under another name                                                                                     | Info     | Accepted: teammates only; see SECURITY.md                                                |
| F6  | Team session (90 days) and participant tokens live in localStorage; an XSS would expose them                                           | Low      | Accepted: XSS is blocked by text-only rendering, strict nonce CSP and Trusted Types      |
| F7  | The team session travels in the `Sec-WebSocket-Protocol` header, which platform request logs may record                                | Low      | Accepted: logs are only visible to the account owner; the session cannot reach admin     |
| F8  | Turnstile with Trusted Types could not be tested end-to-end here (no route to Cloudflare from the sandbox)                             | Medium   | Open: owner checks the console on staging (docs/setup.md part 4)                         |
| F9  | CSP allows any script from `challenges.cloudflare.com`                                                                                 | Info     | Accepted: Cloudflare-controlled, required by Turnstile                                   |
| F10 | Importing Zod as a namespace object put all of it in the bundle (730 kB)                                                               | Info     | Fixed: `import * as z from 'zod/mini'`, bundle 296 kB (83 kB compressed)                 |

## Residual risk

Low, provided the owner picks a strong team key and confirms F8 on staging.
The attack surface without the team key is now one endpoint (`/api/session`),
rate limited. With the team key, a teammate can do what any participant can
do, and the host role is enforced on the server.
